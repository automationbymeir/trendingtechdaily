עודכן לאחרונה: אפריל 2025

מדיניות פרטיות זו מסבירה כיצד TrendingTech Daily, המופעל על ידי מאיר אוטומציות (עוסק פטור, מדרגות הכפר 12, ירושלים), אוסף, משתמש ומגן על המידע האישי שלך. בשימוש באתר, אתה מסכים לנוהלים המתוארים להלן.

מידע שאנו אוספים

  • פרטים מזהים — שם וכתובת דוא"ל שאתה מספק בעת ההרשמה או יצירת קשר.
  • נתוני שימוש — דפים שנצפו, זמן שהייה בדפים ואינטראקציות עם תכונות האתר.
  • נתוני מכשיר ודפדפן — באמצעות עוגיות (cookies) וטכנולוגיות מעקב דומות.
  • נתוני אימות — מידע שנשמר בעת כניסה לחשבון דרך Firebase Authentication.

כיצד אנו משתמשים במידע

המידע שלך מסייע לנו:

  • לספק ולהתאים אישית תוכן, כולל סרטוני YouTube מוטמעים.
  • לשפר ולתקן תקלות באתר ובשירותים שלנו.
  • להגיש פרסומות ותוכן של צדדים שלישיים דרך שירותי API משולבים.
  • לשתף נתונים מצטברים ואנונימיים עם ספקי שירות חיצוניים.

שימוש בשירותי YouTube API

אנו משתמשים בשירותי YouTube API להטמעת סרטונים והמלצות תוכן. השימוש שלנו ב-YouTube API כפוף לתנאי שירות YouTube API. בצפייה בסרטונים באתרנו, אתה מסכים לאינטגרציה זו.

תוכן ופרסומות של צדדים שלישיים

אנו מאפשרים לצדדים שלישיים (כגון רשתות פרסום) להציג תוכן ופרסומות באתרנו. שותפים אלה עשויים להשתמש בעוגיות או בטכנולוגיות דומות כדי לאסוף מידע על השימוש שלך באתר ובאתרים אחרים.

עוגיות וטכנולוגיות דומות

אנו ושותפינו משתמשים בעוגיות, web beacons וטכנולוגיות מעקב נוספות לצורך אספקת, ניתוח ושיפור שירותינו. ניתן לנהל או לבטל עוגיות דרך הגדרות הדפדפן שלך; עם זאת, חלק מהפונקציות עשויות שלא לפעול כראוי ללא עוגיות.

שיתוף מידע

אנו עשויים לשתף את המידע שלך עם:

  • צוות פנימי: לצורך אנליטיקה, תמיכה ותחזוקת האתר.
  • ספקי שירות: כגון אחסון, אנליטיקה ושותפי פרסום.
  • רשויות חוק: אם נדרש על פי חוק או להגנה על זכויותינו.
